# BeatGuess — SongPop-style web quiz

A static, mobile-friendly music quiz with solo play and two-player pass-and-play Quick Match. Open `index.html` locally, or deploy the folder to GitHub Pages.

## Two-player Quick Match

1. Choose **Two-player Quick Match** on the home screen.
2. Player 1 hears the clip and selects an answer.
3. Pass the phone and tap **I’m Player 2 — play clip**.
4. Player 2 hears the same clip and selects independently.
5. After 10 rounds, the app reveals the winner.

## Deploy free with GitHub Pages

1. Create a GitHub account and a new **public** repository, e.g. `beatguess`.
2. Upload `index.html` and this README to the repository.
3. Go to **Settings → Pages**.
4. Under **Build and deployment**, choose **Deploy from a branch**.
5. Select `main` and `/ (root)`, then save.
6. Open `https://YOUR-USERNAME.github.io/beatguess/` after deployment.

## Add songs

Use **My song pack** to select audio files from your phone or computer. Files remain in the browser and are not uploaded. Name files `Artist - Title.mp3` for automatic metadata.

Only add music you own, have permission to use, or that is royalty-free. Do not publish copyrighted commercial recordings on a public site.
